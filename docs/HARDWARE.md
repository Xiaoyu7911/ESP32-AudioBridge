# 硬件与连接

## 端口分工

| 设备 / 接口 | 连接到 | 作用 |
| :--- | :--- | :--- |
| 麦克风 | 声卡 | 原有人声输入 |
| 声卡 USB | 电脑 | 采集、机架处理、耳机监听 |
| 开发板 COM / CH343P 口 | 电脑 | 将帧协议 PCM 送入 ESP32-S3 UART |
| 开发板原生 USB 口 | 手机 | 作为 USB Audio 麦克风输入 |

本项目使用 ESP32-S3 双 USB 开发板，固件沿用该板已验证的 UART0 配置。CH343P 口不是 USB 声卡。接口必须按板上丝印及 USB 枚举识别，不按左右位置猜测；其他板型的 UART 引脚和供电电路需要核对。

## 手机连接

- **iPhone 14 Pro**：Lightning 端需要合适的 USB Host 转接方式，普通充电线不能等同于 USB Host 相机转接器。
- **iPhone 17**：USB-C 数据连接；具体线缆 / 转接方式以已验证的设备组合为准。
- **小米 10**：USB-C 数据连接，手机需支持并启用相应 USB Host / OTG 功能。

用户已确认上述三款手机的单声道使用测试通过，但没有逐项提供转接器型号、系统及 App 版本。本发布包不据此推定所有线材和录音 App 都兼容。通过录音静音对照等方法确认录到的是桥接音频，而非内置麦克风。

## 供电与使用要点

双 USB 同时连接电脑和手机前，核对具体 PCB 的两路 VBUS 隔离与 USB 角色设计。项目使用过的板卡由使用者确认隔离；其他同名或兼容板不能直接沿用此结论。请勿自行短接两台主机的 5 V 或盲目改线。

麦克风 UAC 接口只占用 ESP32-S3 原生 USB；该口此时不同时用作 USB Host 或 USB Serial/JTAG。UART0 在音频传输时只发送协议帧，不混入日志。刷写工具、串口监视器和音频发送器也不应同时占用同一端口。

监听原有机架效果时，请根据需要关闭声卡 Direct Monitor，避免同时听到干声与湿声。不要把 ESP32 返回的 USB 麦克风选作发送输入，以免形成反馈。
